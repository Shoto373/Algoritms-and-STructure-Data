### Задача A. №3557. Бинарное дерево (вставка, поиск, удаление)

- **Алгоритм:** Двоичное дерево поиска (BST) с ручной реализацией операций вставки, поиска, удаления и структурированного вывода.
- **Сложность:** В среднем $O(H)$, в худшем $O(N)$ на операцию ($H$ — высота дерева).
- **Решения:** [Python](Python/A.py)

**Условие:**  
Напишите программу, которая будет реализовывать действия в бинарном дереве поиска «вставить», «удалить» и «найти» (по значению). Программа должна обрабатывать запросы четырёх видов:
- `ADD n` — если указанного числа еще нет в дереве, вставлять его и выводить слово `DONE`, если уже есть — оставлять дерево как было и выводить слово `ALREADY`.
- `DELETE n` — если указанное число есть в дереве, удалять его и выводить слово `DONE`, если нет — оставлять дерево как было и выводить слово `CANNOT`. При удалении элемента, имеющего два сына, обязательно обменивать значение с максимальным элементом левого поддерева.
- `SEARCH` — следует выводить слово `YES` (если значение найдено в дереве) или слово `NO` (если не найдено). Дерево при этом не меняется.
- `PRINTTREE` — выводить все дерево, обязательно используя алгоритм, указанный в формате вывода результатов.

**Входные данные:**  
В каждой строке входных данных записан один из запросов `ADD n` или `DELETE n` или `SEARCH n` или `PRINTTREE`. Общее количество запросов не превышает 1000, из них не более 20 запросов `PRINTTREE`.

**Выходные данные:**  
Для каждого запроса выводите ответ на него. Для запроса `PRINTTREE` выводить дерево с отступами точками (`.`) пропорционально глубине узла (центрированный обход).

### Задача K. №2782. Следующий

- **Алгоритм:** BST с поддержкой операции `next(i)` (поиск минимального элемента $\ge i$, аналог `lower_bound`), а также динамической модификацией входных данных: `add((i + y) mod 10^9)`.
- **Сложность:** $O(H)$ на запрос
- **Решения:** [Python](Python/K.py)

**Условие:**  
Реализуйте структуру данных, которая поддерживает множество $S$ целых чисел, с котором разрешается производить следующие операции:
- `add(i)` — добавить в множество $S$ число $i$ (если оно там уже есть, то множество не меняется);
- `next(i)` — вывести минимальный элемент множества, не меньший $i$. Если искомый элемент в структуре отсутствует, необходимо вывести -1.

Если операция `+ i` идет во входном файле в начале или после другой операции `+`, то она задает операцию `add(i)`. Если же она идет после запроса `?`, и результат этого запроса был $y$, то выполняется операция `add((i + y) mod 10^9)`.

**Входные данные:**  
Исходно множество $S$ пусто. Первая строка входного файла содержит $n$ — количество операций ($1 \le n \le 300\,000$). Следующие $n$ строк содержат операции `+ i` или `? i`. Во всех запросах и операциях добавления параметры лежат в интервале от 0 до $10^9$.

**Выходные данные:**  
Для каждого запроса `?` выведите одно число — ответ на запрос.

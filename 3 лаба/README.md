### Задача A. №55. Стек с защитой от ошибок

- **Алгоритм:** Стек с проверкой на пустоту
- **Сложность:** O(1) на запрос
- **Решения:** [Python](Python/A.py)

**Условие:**  
Реализуйте структуру данных «стек». Напишите программу, содержащую описание стека и моделирующую его работу, реализовав все указанные методы:
- `push n` — добавить в стек число `n` (вывести `ok`);
- `pop` — удалить из стека последний элемент (вывести его значение);
- `back` — вывести значение последнего элемента, не удаляя его;
- `size` — вывести количество элементов в стеке;
- `clear` — очистить стек (вывести `ok`);
- `exit` — вывести `bye` и завершить работу.

Перед исполнением операций `pop` и `back` программа должна проверять, содержится ли в стеке хотя бы один элемент. Если происходит попытка вызова операции `pop` или `back` для пустого стека, программа должна вывести строку `error`.

### Задача E. №60. Дек с защитой от ошибок

- **Алгоритм:** Двусторонняя очередь (Deque)
- **Сложность:** O(1) на запрос
- **Решения:** [Python](Python/E.py)

**Условие:**  
Реализуйте структуру данных «дек» (двусторонняя очередь) со следующими методами:
- `push_front n` — добавить элемент `n` в начало дека (вывести `ok`);
- `push_back n` — добавить элемент `n` в конец дека (вывести `ok`);
- `pop_front` — извлечь элемент из начала дека (вывести его значение);
- `pop_back` — извлечь элемент из конца дека (вывести его значение);
- `front` — вывести значение первого элемента без удаления;
- `back` — вывести значение последнего элемента без удаления;
- `size` — вывести размер дека;
- `clear` — очистить дек (вывести `ok`);
- `exit` — вывести `bye` и завершить работу.

Если вызывается `pop_front`, `pop_back`, `front` или `back` для пустого дека, выводить `error`.

### Задача K. №3569. Хорошие дни

- **Алгоритм:** Монотонный стек + префиксные суммы
- **Сложность:** O(N)
- **Решения:** [Python](Python/K.py)

**Условие:**  
Дан массив неотрицательных чисел $A$ длины $N$. Для каждого подотрезка $[l, r]$ определяется его ценность как произведение минимального элемента на сумму всех элементов подотрезка:
$$\text{value}(l, r) = \min_{l \le i \le r}(A[i]) \times \sum_{i=l}^r A[i]$$
Найти максимальную возможную ценность подотрезка, а также границы $l$ и $r$ (в 1-индексации), на которых этот максимум достигается.

### Задача A. №111156. Сортировка выбором

- **Алгоритм:** Сортировка выбором (Selection Sort)
- **Сложность:** O(N²) время, O(1) память
- **Решения:** [C++](C++/A.cpp), [Python](Python/A.py)

**Условие задачи:**  
Дан список целых чисел. Выведите все элементы этого списка в порядке невозрастания значений (от большего к меньшему). Выведите полученный список на экран. Решите эту задачу при помощи алгоритма сортировки выбором. Решение оформите в виде функции `SelectionSort(A)`.

**Суть простыми словами:**  
Нам дан массив чисел в случайном порядке. Нужно переставить их так, чтобы в начале стояло самое большое число, затем поменьше, и в самом конце — самое маленькое.

**Как работает алгоритм на пальцах:**  
1. Ищем во всем массиве самое большое число (максимум).
2. Меняем этот найденный максимум местами с числом, которое сейчас стоит на первом месте (индекс 0). Теперь первое число точно стоит там, где нужно.
3. Смотрим на оставшуюся часть массива (со 2-го элемента и до конца). Снова находим среди них максимум и меняем его со вторым элементом (индекс 1).
4. Повторяем этот шаг для 3-го, 4-го и всех последующих элементов.
5. Когда доходим до конца, весь массив оказывается отсортирован по невозрастанию.

**Пример работы:**  
- Исходный массив: `[3, 1, 5, 2]`
- Шаг 1: Максимум среди всех — `5`. Меняем `5` и `3` местами: `[5, 1, 3, 2]`
- Шаг 2: Ищем максимум среди `[1, 3, 2]` — это `3`. Меняем `3` и `1`: `[5, 3, 1, 2]`
- Шаг 3: Ищем максимум среди `[1, 2]` — это `2`. Меняем `2` и `1`: `[5, 3, 2, 1]`
- Итог: `[5, 3, 2, 1]`

**Почему сложность O(N²):**  
Внешний цикл делает N шагов. На каждом шаге внутренний цикл просматривает оставшиеся элементы для поиска максимума (сначала N, потом N-1, N-2 и т.д.). Общее число операций пропорционально N * N / 2, то есть O(N²).

### Задача B. №111157. Сортировка вставкой

- **Алгоритм:** Сортировка вставкой (Insertion Sort)
- **Сложность:** O(N²) худшее, O(N) лучшее время, O(1) память
- **Решения:** [C++](C++/B.cpp), [Python](Python/B.py)

**Условие задачи:**  
Дан список целых чисел. Отсортируйте его в порядке неубывания значений (по возрастанию). Выведите полученный список на экран. Решите эту задачу при помощи алгоритма сортировки вставкой. Решение оформите в виде функции `InsertionSort(A)`.

**Суть простыми словами:**  
Это то, как люди обычно сортируют карты в руке. Вы берете по очереди каждую карту и сдвигаете ее влево, пока она не окажется на своем правильном месте среди уже отсортированных карт.

**Как работает алгоритм на пальцах:**  
1. Первый элемент массива сам по себе уже считается «отсортированным».
2. Берем второй элемент и запоминаем его значение в переменную `x`.
3. Сравниваем `x` с элементами слева от него. Если элемент слева больше `x`, мы сдвигаем этот большой элемент вправо на одну позицию.
4. Повторяем сдвиг, пока не найдем элемент, который меньше либо равен `x` (или пока не дойдем до начала массива).
5. В освободившуюся позицию вставляем наш сохраненный `x`.
6. Берем следующий элемент и повторяем то же самое, пока массив не закончится.

**Пример работы:**  
- Исходный массив: `[4, 2, 5, 1]`
- Берем `2`: сравниваем с `4`. Так как `4 > 2`, сдвигаем `4` вправо, на ее место ставим `2`: `[2, 4, 5, 1]`
- Берем `5`: сравниваем с `4`. Так как `5 >= 4`, ничего сдвигать не нужно: `[2, 4, 5, 1]`
- Берем `1`: сравниваем с `5` (сдвиг), с `4` (сдвиг), с `2` (сдвиг). Ставим `1` в начало: `[1, 2, 4, 5]`
- Итог: `[1, 2, 4, 5]`

**Почему сложность O(N²):**  
Для каждого из N элементов в худшем случае (когда массив изначально перевернут задом наперед) приходится сдвигать все предыдущие элементы. Поэтому число операций доходит до O(N²). Если же массив уже был отсортирован, внутренний цикл сразу завершается, и алгоритм отработает за O(N).

### Задача C. №111158. Сортировка пузырьком

- **Алгоритм:** Сортировка пузырьком (Bubble Sort)
- **Сложность:** O(N²) время, O(1) память
- **Решения:** [C++](C++/C.cpp), [Python](Python/C.py)

**Условие задачи:**  
Дан список целых чисел. Отсортируйте его в порядке неубывания значений. Выведите полученный список на экран. Решите эту задачу при помощи алгоритма пузырьковой сортировки. Решение оформите в виде функции `BubbleSort(A)`.

**Суть простыми словами:**  
Алгоритм сравнивает соседние числа попарно. Если левое число больше правого, они меняются местами. За счет этого самые большие числа шаг за шагом «всплывают» в конец массива, точно как пузырьки воздуха в воде.

**Как работает алгоритм на пальцах:**  
1. Начинаем с начала массива. Сравниваем первую пару: `arr[0]` и `arr[1]`. Если первое число больше второго — меняем их местами.
2. Переходим к следующей паре: `arr[1]` и `arr[2]`. Снова сравниваем и при необходимости меняем.
3. Доходим до конца массива. В результате этого первого полного прохода самое большое число гарантированно окажется на самом последнем месте.
4. Начинаем второй проход с начала, но теперь идем до предпоследнего элемента (ведь последний уже на месте). Второй по величине элемент встанет на предпоследнее место.
5. Делаем такие проходы N - 1 раз, пока весь массив не упорядочится.

**Пример работы:**  
- Исходный массив: `[5, 1, 4, 2]`
- Сравниваем `5` и `1`: `5 > 1`, меняем -> `[1, 5, 4, 2]`
- Сравниваем `5` и `4`: `5 > 4`, меняем -> `[1, 4, 5, 2]`
- Сравниваем `5` и `2`: `5 > 2`, меняем -> `[1, 4, 2, 5]` (число 5 заняло свое идеальное место)
- Следующий проход по `[1, 4, 2]` меняет `4` и `2` местами: `[1, 2, 4, 5]`
- Итог: `[1, 2, 4, 5]`

### Задача D. №1411. Пузырек: количество обменов

- **Алгоритм:** Пузырьковая сортировка с подсчетом перестановок
- **Сложность:** O(N²) время, O(1) память
- **Решения:** [C++](C++/D.cpp), [Python](Python/D.py)

**Условие задачи:**  
Определите, сколько обменов сделает алгоритм пузырьковой сортировки по возрастанию для данного массива.

**Суть простыми словами:**  
Здесь не нужно выводить сам отсортированный массив. Нужно запустить алгоритм пузырьковой сортировки и аккуратно сосчитать, сколько именно раз внутри алгоритма сработала операция перемены двух соседних элементов местами (`swap`).

**Как работает алгоритм на пальцах:**  
1. Заводим переменную-счетчик: `count = 0`.
2. Запускаем стандартные два вложенных цикла пузырьковой сортировки.
3. Всякий раз, когда видим, что левый элемент больше правого (`arr[j] > arr[j + 1]`), мы:
   - Меняем их местами;
   - Прибавляем единицу к счетчику: `count += 1`.
4. После окончания всех циклов выводим значение `count`.

**Пример работы:**  
- Массив: `[3, 2, 1]`
- Сравниваем `3` и `2`: меняем местами -> `[2, 3, 1]`, счетчик = 1
- Сравниваем `3` и `1`: меняем местами -> `[2, 1, 3]`, счетчик = 2
- Следующий проход: сравниваем `2` и `1`: меняем -> `[1, 2, 3]`, счетчик = 3
- Ответ: `3`

### Задача E. №766. Сортировка слиянием

- **Алгоритм:** Сортировка слиянием (Merge Sort)
- **Сложность:** O(N log N) время, O(N) память
- **Решения:** [C++](C++/E.cpp), [Python](Python/E.py)

**Условие задачи:**  
Отсортируйте данный массив, используя сортировку слиянием.

**Суть простыми словами:**  
Алгоритм работает по принципу «разделяй и властвуй». Рассортировать огромный массив сложно. Но если разделить его пополам, отсортировать каждую половину отдельно, а затем аккуратно «слить» две уже упорядоченные половины в один общий список — задача решается очень быстро.

**Как работает алгоритм на пальцах:**  
1. **Базовый случай:** Если в массиве 1 элемент или 0 элементов, он уже отсортирован. Возвращаем его.
2. **Разделение:** Находим середину массива и делим его на две равные части — левую (`left`) и правую (`right`). Рекурсивно вызываем сортировку слиянием для каждой половины.
3. **Слияние (`merge`):**
   - Имеем два отсортированных списка, например `[2, 5]` и `[1, 6]`.
   - Ставим два указателя: один на начало левого списка, второй на начало правого.
   - Сравниваем элементы, на которые указывают указатели. Меньший элемент забираем в итоговый массив и сдвигаем указатель вперед.
   - Когда один из списков опустел, остаток другого списка просто дописываем в конец.

**Пример слияния:**  
- Сливаем `[2, 5]` и `[1, 6]`:
  - Смотрим на `2` и `1`: `1 < 2`, берем `1`. Результат: `[1]`
  - Смотрим на `2` и `6`: `2 < 6`, берем `2`. Результат: `[1, 2]`
  - Смотрим на `5` и `6`: `5 < 6`, берем `5`. Результат: `[1, 2, 5]`
  - В левом списке элементы кончились, дописываем оставшуюся `6`: `[1, 2, 5, 6]`

**Почему сложность O(N log N):**  
Массив длины N можно разделить пополам ровно log₂(N) раз (это глубина дерева рекурсии). На каждом уровне рекурсии операция слияния просматривает все N элементов. Поэтому суммарное время всегда строго O(N log N).

### Задача F. №733. Быстрая сортировка

- **Алгоритм:** Быстрая сортировка (Quick Sort / Сортировка Хоара)
- **Сложность:** O(N log N) среднее, O(N²) худшее время, O(log N) память
- **Решения:** [C++](C++/F.cpp), [Python](Python/F.py)

**Условие задачи:**  
Отсортируйте данный массив. Используйте быструю сортировку.

**Суть простыми словами:**  
Выбираем из массива один любой элемент и называем его «опорным» (pivot). Затем раскидываем все остальные числа по двум группам: те, что меньше опорного — налево, те, что больше — направо. Сам опорный элемент оказывается ровно на своем законном месте. Повторяем ту же процедуру для левой и правой групп.

**Как работает алгоритм на пальцах:**  
1. Если массив пустой или из одного элемента — возвращаем его (он уже отсортирован).
2. Выбираем опорный элемент `pivot` (например, берем число из середины массива).
3. Разбиваем массив на три части:
   - `left`: все элементы, которые строго меньше `pivot`;
   - `mid`: все элементы, которые равны `pivot`;
   - `right`: все элементы, которые строго больше `pivot`.
4. Рекурсивно запускаем быструю сортировку для `left` и для `right`.
5. Склеиваем результат: `quicksort(left) + mid + quicksort(right)`.

**Пример работы:**  
- Исходный массив: `[3, 6, 8, 1, 2, 1]`. Выберем опорный элемент `pivot = 2`.
- `left` (меньше 2): `[1, 1]`
- `mid` (равно 2): `[2]`
- `right` (больше 2): `[3, 6, 8]`
- Рекурсивно сортируем `left` (он уже `[1, 1]`) и `right` (он станет `[3, 6, 8]`).
- Склеиваем: `[1, 1] + [2] + [3, 6, 8] = [1, 1, 2, 3, 6, 8]`.

### Задача G. №111166. Сортировка подсчетом

- **Алгоритм:** Сортировка подсчетом (Counting Sort)
- **Сложность:** O(N + K) время, O(K) память (где K = 101)
- **Решения:** [C++](C++/G.cpp), [Python](Python/G.py)

**Условие задачи:**  
Дан список из N элементов (N <= 2·10⁵), которые принимают целые значения от 0 до 100. Отсортируйте этот список в порядке неубывания элементов. Требуемая сложность — линейная O(N).

**Суть простыми словами:**  
Когда чисел очень много (200 000), но диапазон возможных значений крошечный (всего от 0 до 100), попарно сравнивать числа бессмысленно и долго. Намного проще поставить 101 «коробку» (по одной для каждого числа от 0 до 100) и просто посчитать, сколько раз встретилось каждое число.

**Как работает алгоритм на пальцах:**  
1. Заводим массив счетчиков размером 101, изначально заполненный нулями: `count[0..100] = 0`.
2. Читаем числа по одному. Встретили число `x`? Увеличиваем счетчик этого числа: `count[x] += 1`.
3. Теперь проходим по массиву счетчиков от 0 до 100: если `count[x] > 0`, выводим число `x` ровно `count[x]` раз подряд.

**Пример работы:**  
- Входные данные: `[3, 1, 3, 0, 1]`
- Счетчик нулей `count[0]` = 1
- Счетчик единиц `count[1]` = 2
- Счетчик двоек `count[2]` = 0
- Счетчик троек `count[3]` = 2
- Собираем ответ по порядку счетчиков: один `0`, две `1`, две `3` -> `[0, 1, 1, 3, 3]`.

**Почему это супер-быстро (O(N)):**  
Мы делаем ровно один проход по входным данным (N шагов) и один проход по массиву счетчиков (101 шаг). Никаких вложенных циклов и тяжелых сравнений.

### Задача H. №325. Сортировка точек

- **Алгоритм:** Сортировка массива структур по кастомному компаратору
- **Сложность:** O(N log N) время, O(N) память
- **Решения:** [C++](C++/H.cpp), [Python](Python/H.py)

**Условие задачи:**  
Выведите все исходные точки плоскости в порядке возрастания их расстояний от начала координат (0, 0). Создайте структуру `Point` и сохраните исходные данные в массиве структур `Point`.

**Суть простыми словами:**  
Даны координаты точек на плоскости: (x, y). Нужно поставить ближе к началу списка те точки, которые ближе к началу координат (0, 0).

**Как работает алгоритм на пальцах:**  
1. Расстояние от точки (x, y) до центра (0, 0) по теореме Пифагора равно корню из `x² + y²`.
2. Извлекать квадратный корень необязательно: если `x₁² + y₁² < x₂² + y₂²`, то и само расстояние первой точки меньше. Работа с целыми квадратами расстояний быстрее и исключает погрешности вещественных чисел.
3. Описываем структуру `Point` с полями `x` и `y`.
4. Задаем правило сравнения двух точек A и B: точка A идет раньше точки B, если `A.x² + A.y² < B.x² + B.y²`.
5. Сортируем список точек с этим правилом стандартной или собственной сортировкой.

**Пример работы:**  
- Точка A: (3, 4) -> квадрат расстояния = `3² + 4² = 9 + 16 = 25`

Слово называется анаграммой другого слова, если оно может быть получено перестановкой его букв.  
Даны два слова на отдельных строках длиной до 255 символов (латинские буквы и цифры).  
Выведите `YES`, если они являются анаграммами друг друга, и `NO` — если нет.  
*Примечание:* Сложность должна быть строго O(n). Использование встроенных и классических сортировок запрещено!

**Суть простыми словами:**  
Анаграмма — это когда два слова состоят из абсолютно одинакового набора букв в одинаковом количестве, просто буквы перетасованы (как «рост» и «сорт»). Если отсортировать слова нельзя по условию, нужно быстро проверить, совпадает ли количество каждой буквы.

5. Если хоть у одной буквы баланс не равен нулю — выводим `NO`, иначе `YES`.

**Пример работы:**

### Задача J. №411. Число

- **Алгоритм:** Жадная сортировка со строковым компаратором `a + b > b + a`
- **Сложность:** O(N log N) время, O(N) память
- **Решения:** [Python](Python/J.py)

**Условие задачи:**  
Даны строки, состоящие из цифр (обрывки разрезанного числа). Нужно составить из них максимально возможное целое число, склеив все строки между собой.

**Суть простыми словами и главная ловушка:**  
Кажется, что нужно просто отсортировать строки по убыванию. Но это ошибка:
- Возьмем строки `'2'` и `'21'`.
- Обычная сортировка поставит `'21'` вперед, и склейка даст `'212'`.
- Но если поставить `'2'` вперед, получится `'221'`! А число 221 больше, чем 212.
- Значит, нужно уметь правильно определять, какая из двух строк при склейке дает лучший результат.

**Как работает алгоритм на пальцах:**  
1. Чтобы узнать, кто должен стоять раньше — строка `A` или строка `B`, мы просто склеиваем их в обоих порядках и сравниваем две получившиеся строчки:
   - Склеиваем `A + B`
   - Склеиваем `B + A`
2. Если `A + B > B + A`, значит строка `A` обязательно должна стоять левее строки `B`.
3. Используем это правило сравнения при сортировке всех строк (например, сортировкой вставками, как в `J.py`).
4. После окончания сортировки склеиваем все строки подряд в одно итоговое число.

**Пример работы:**  
- Даны строки: `['2', '21']`
- Сравниваем: `'2' + '21' = '221'`, а `'21' + '2' = '212'`.
- Так как `'221' > '212'`, строка `'2'` идет перед `'21'`.
- Ответ: `221`.

### Задача K. №665. Анти-QuickSort

- **Алгоритм:** Конструктивное построение худшего теста для QuickSort
- **Сложность:** O(N) время, O(N) память
- **Решения:** [Python](Python/K.py)

**Условие задачи:**  
Для сортировки последовательности чисел используется быстрая сортировка, где опорным элементом выбирается элемент из середины отрезка (`arr[i // 2]`). Напишите программу, которая генерирует такую перестановку чисел от 1 до N, на которой эта быстрая сортировка выполнит максимальное возможное число сравнений (O(N²)).

**Суть простыми словами:**  
Быстрая сортировка работает эффективно (за O(N log N)), когда опорный элемент делит массив примерно пополам. Но если опорный элемент каждый раз оказывается самым большим числом в текущем куске, массив не делится пополам, а лишь уменьшается на 1 элемент. В результате алгоритм делает максимум сравнений — около N² / 2. Наша задача — сгенерировать такой массив-ловушку.

**Как работает алгоритм на пальцах:**  
Мы строим худший тест, «раскручивая» работу алгоритма задом наперед:
1. Создаем массив упорядоченных чисел: `[1, 2, 3, ..., N]`.
2. Запускаем цикл от 2 до N - 1:
   - На каждом шаге меняем местами текущий элемент с элементом из середины: `res[i], res[i // 2] = res[i // 2], res[i]`.
3. Каждая такая перестановка как раз прячет наибольшее число на позицию середины, в которую полезет алгоритм при выборе опорного элемента.
4. В результате получается массив, который на каждом шаге QuickSort дает наихудшее возможное разбиение.

**Пример для N = 4:**  
- Старт: `[1, 2, 3, 4]`
- i = 2, середина = 1: меняем `res[2]` (3) и `res[1]` (2) -> `[1, 3, 2, 4]`
- i = 3, середина = 1: меняем `res[3]` (4) и `res[1]` (3) -> `[1, 4, 2, 3]`
- На этом массиве QuickSort сделает максимальное число сравнений.

### Задача L. №111162. Такси

- **Алгоритм:** Жадный алгоритм (неравенство перестановки)
- **Сложность:** O(N log N) время, O(N) память
- **Решения:** [Python](Python/L.py)

**Условие задачи:**  
Директору компании нужно развезти N сотрудников на N машинах такси. Известно расстояние до дома каждого сотрудника в километрах и тариф за 1 километр для каждого такси. Каждому сотруднику выделяется отдельная машина. Определите минимальную сумму, которую придется заплатить за проезд всех сотрудников.

**Суть простыми словами:**  
Стоимость поездки сотрудника — это его расстояние, умноженное на тариф такси. Кого в какую машину посадить, чтобы общая сумма была наименьшей?
- Интуиция простая: если сотруднику ехать очень далеко, ему нужно дать самую дешевую машину (с минимальным тарифом), иначе счет за поездку будет космическим!
- А тем, кому ехать близко (1-2 км), можно безболезненно дать машины с дорогими тарифами — переплата будет копеечной.

**Как работает алгоритм на пальцах:**  
1. Сортируем расстояния сотрудников по возрастанию: от самых близких к самым далеким.
2. Сортируем тарифы такси по убыванию: от самых дорогих к самым дешевым.
3. Сопоставляем их попарно: сотруднику с самым маленьким расстоянием даем самое дорогое такси, а сотруднику с самым большим расстоянием — самое дешевое.
4. Перемножаем пары и складываем их произведения в общую сумму. В математике этот принцип строго доказан и называется *неравенством перестановки*.

**Пример работы:**  
- Расстояния: `[10, 1]` (один едет на 10 км, другой на 1 км)
- Тарифы: `[50, 5]` (одно такси по 50 руб/км, другое по 5 руб/км)
- Сортируем расстояния по возрастанию: `[1, 10]`
- Сортируем тарифы по убыванию: `[50, 5]`
- Считаем стоимость: `1 * 50 + 10 * 5 = 50 + 50 = 100` рублей (минимально возможная сумма).

## Задачи

### Задача A. №755. Хипуй!!!

- **Алгоритм:** Двоичная куча с ручной реализацией (без готовых структур)
- **Сложность:** O(log N) на операцию
- **Решения:** [Python](Python/A.py)

**Условие:**  
Необходимо организовать структуру данных Heap для хранения целых чисел, над которой определены следующие операции:
- `0 k` (`Insert(k)`) — добавить в Heap число $k$ ($1 \le k \le 1\,000\,000$);
- `1` (`Extract`) — достать из Heap наибольшее число (удалив его при этом).

Во входной строке сначала задаётся количество команд $N$ ($1 \le N \le 100\,000$), далее следуют $N$ команд. Гарантируется, что при выполнении команды Extract в структуре находится хотя бы один элемент.  
Для каждой команды Extract вывести результат в отдельной строке.

- **Сложность:** O(log N) на операцию
- **Решения:** [Python](Python/C.py) / [C++](C++/C.cpp)

**Условие:**  
Задача отличается от «Пирамида (максимум)» исключительно тем, что надо извлекать не максимум, а минимум. Напишите программу, обрабатывающую последовательность запросов:

Суммарное количество запросов не превышает 200 000. Реализация на C++ — собственная, без STL-кучи.

### Задача G. №3407. Вычислительная ихтиология

- **Алгоритм:** Симуляция с min-кучей событий (событийное моделирование)
- **Сложность:** O(N log N)
- **Решения:** [Python](Python/G.py)

**Условие:**  
В НИИ ихтиологии стоят $N$ аквариумов в ряд. В каждом живёт колония рыбок гуппи начального размера $a_i$. Колония размера $f$ рождает новую рыбку каждые $\max(1000 - f, 1)$ секунд, после чего размер увеличивается на 1.  
Игорь стоит у первого аквариума в момент 0, перемещение между соседними аквариумами занимает 1 секунду. При рождении рыбки Игорь должен находиться рядом с аквариумом.  
Найти момент времени первого рождения, на котором Игорь не сможет присутствовать.
